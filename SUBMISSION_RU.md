# Что загрузить в задание

1. Создай на GitHub новый репозиторий `onlinecourse-final-project`. Выбери Public. При создании добавь README, чтобы появилась ветка `main`.
2. Распакуй ZIP. Открой папку `onlinecourse-project`.
3. На странице репозитория нажми Add file → Upload files.
4. Перетащи содержимое папки: `manage.py`, `requirements.txt`, папки `myproject`, `onlinecourse`, `screenshots` и остальные файлы. Не загружай внешнюю папку `onlinecourse-project` целиком, иначе пути будут отличаться.
5. Нажми Commit changes.
6. Открой каждый файл из таблицы и скопируй адрес страницы. В ссылках ниже замени YOUR_USERNAME на свой логин GitHub. Это образцы: пока файлы не загружены, они не работают.

| Вопрос | Что вставить или загрузить |
| --- | --- |
| 1 | https://github.com/YOUR_USERNAME/onlinecourse-final-project/blob/main/onlinecourse/models.py |
| 2 | https://github.com/YOUR_USERNAME/onlinecourse-final-project/blob/main/onlinecourse/admin.py |
| 3 | Файл `screenshots/03-admin-site.png` |
| 4 | https://github.com/YOUR_USERNAME/onlinecourse-final-project/blob/main/onlinecourse/templates/onlinecourse/course_details_bootstrap.html |
| 5 | https://github.com/YOUR_USERNAME/onlinecourse-final-project/blob/main/onlinecourse/views.py |
| 6 | https://github.com/YOUR_USERNAME/onlinecourse-final-project/blob/main/onlinecourse/urls.py |
| 7 | Файл `screenshots/07-final.png` |

В вопросах 1, 2, 4, 5, 6 требуются именно ссылки на файлы GitHub. ZIP и ссылки на скачивание сюда не подходят.

Скриншоты сделаны с запущенного приложения из этого архива. На странице результата показана реальная локальная попытка с результатом 100%. Для самостоятельного повторения запусти проект по README. Правильные ответы: 1 — Models; 2 — save(); 3 — csrf_token; 4 — ManyToManyField; 5 — Validate the selected choices и Save the submission.

После заполнения всех семи вопросов нажми Submit assignment. Оценку выставляет платформа; она не гарантирована заранее.
